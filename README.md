# 静默之前（Before the Silence）

> **2026 年秋。** 外星寄生孢子 AE-219 最早坠落点——城区仓库区。EDAA 甄别处二级探员「提灯」先行渗透：确认孢子活动、保持信标，撑到熄烛者（Snuffers）01 队「雷暴」进场之前。
>
> *Before the Silence — a retro boomer shooter, prequel to Snuffers. Infiltrate the warehouse district where the alien spores first fell, and hold out until the Snuffers arrive.*

「静默之前」是一款复古第一人称射击游戏（《Snuffers》前传），仓库内包含**双引擎**实现：SDL2 + C++17 原版，以及采用「真 3D 几何 + 复古呈现层」技术的 Godot 4.6 重制版。节奏快、不刷分、不拖沓——拿枪，向前，活着撤离。

> 开发进度与 AI 协作交接 → [STATUS.md](STATUS.md)

## 世界观与关卡

- **第一关 · 前哨站废墟**：诺亚生物科技外围哨站，地表感染区。沿途搜集补给，避免恋战，抵达仍在发送信号的撤离信标。
- **第二关 · 地下研究所**：事故源头——哨站地下失控的生物实验设施。主控核心仍在运转，实验体巢穴围绕其分布，精英变异体的攻击远比地表个体致命。

通关条件：抵达撤离信标。死亡即「信号中断」，公司将该区域标记为彻底失控。

HUD 右上角提供实时小地图（墙体 / 敌人 / 信标 / 玩家朝向），防止迷宫迷路。

## 武器与拾取

游戏现有三把武器。手枪与冲锋枪共享普通弹药备弹池；霰弹枪使用独立的 12 号霰弹。冲锋枪和霰弹枪均需在场景中拾取获得（每张地图各 1 把），首次拾取会补满弹匣并自动切换。第一关的霰弹枪位于北部仓库，12 号霰弹补给按推进路线分布（第一关 8 处、第二关 4 处，每箱 +6 发）。

| 武器 | 类型 | 弹匣（基础/一阶/二阶/三阶） | 单发伤害（基础/一阶/二阶/三阶） | 弹丸数 | 获取方式 |
| --- | --- | --- | --- | --- | --- |
| 手枪 | 半自动（三阶转全自动） | 20 / 25 / 30 / 33 发 | 32 / 36 / 45 / 55 | 1 | 初始持有 |
| 冲锋枪 | 全自动 | 30 / 40 / 50 / 60 发 | 32 / 36 / 45 / 55 | 1 | 场景拾取（金色光晕标识） |
| 霰弹枪 | 泵动式（二阶转半自动、三阶转低速全自动） | 8 / 12 / 16 / 24 发 | 每颗弹丸 20 / 25 / 30 / 40 | 6 / 7 / 8 / 10 | 场景拾取（北部仓库） |

进阶数值由**通用武器升级组件**提供（每张地图一/二/三阶各 1 个，按玩家推进路线分散放置，需按顺序获取：越级拾取会被拒收并保留原地）。手枪/冲锋枪每阶射速 +10，三阶封顶 40；霰弹枪使用独立射速曲线 1.2 → 1.5 → 2.2 → 3.0，并在二阶取消泵动上膛、三阶转为低速全自动。满级后地图上的组件不再可拾取。

| 符号 | 拾取物 | 效果 |
| --- | --- | --- |
| H | 急救包 | 恢复生命（生命已满时不可拾取，保留原地） |
| C | 数据芯片 | 升级货币 |
| A | 弹药箱 | 补充后备弹药 |
| e | 防护服电池 | 补充 10 点防护服能量（先于生命承受伤害，满能量不可拾取） |
| h | 纳米强化剂 | 消耗 10 芯片，提升生命上限 |
| W | 冲锋枪 | 获得冲锋枪 |
| T | 霰弹枪 | 获得霰弹枪；第一关位于北部仓库 |
| s | 12 号霰弹箱 | 为霰弹枪补充 6 发独立备弹 |
| u | 一阶武器升级组件 | 弹匣扩容 + 伤害/射速提升（青色光晕标识） |
| U | 二阶武器升级组件 | 弹匣 + 伤害/射速再强化（紫色光晕标识，需先完成一阶改装） |
| v | 三阶武器升级组件 | 极限改装：冲锋枪 60 发，手枪 33 发 + 全自动（金黄色光晕标识，需先完成二阶改装） |

## 双引擎架构

### Godot 重制版（活跃开发）

路线 B 方案：**真 3D 几何 + 复古呈现层**。

- Godot 4.6，GDScript
- 240×135 低分辨率 SubViewport + 最近邻过滤，还原像素颗粒感
- 距离雾 + billboard 精灵（敌人 / 拾取物），营造 DOOM 式氛围
- 配置驱动：与 C++ 版共用同一套 JSON 数据源（`assets/config/*.json`），关卡由 LevelData 程序化生成，双版本数值同源

### C++ 原版（归档维护）

- SDL2 + C++17，5 层架构
- 127 项单元测试全部通过，零编译警告
- 双地图 / 3 难度 / 完整游戏循环，raycasting 伪 3D 渲染

## 快速开始

### Godot 版（推荐）

1. 安装 Godot 4.6+：`winget install GodotEngine.GodotEngine`
2. 双击 `启动Godot版.bat`

也可以直接在 Godot 编辑器中导入 `godot/` 目录运行。

### C++ 版

- **直接游玩**：运行 `dist-v1.0.1.0/Retro First Person Shooter.exe`（含运行库安装程序）
- **源码构建**：需要 MSVC + CMake + vcpkg

```bat
cmake --build build --config Release --target RetroFPS
启动游戏.bat
```
