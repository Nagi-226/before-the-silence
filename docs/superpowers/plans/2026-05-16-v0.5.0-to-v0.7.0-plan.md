# Retro FPS v0.5.0 → v0.7.0 详细实现计划

> **起点:** v0.5.0 — 127 测试、零警告、全渲染特性就绪
> **终点:** v0.7.0 — 完整成品（2 关精心打磨的关卡 + 全音效 + 菜单 + 存档 + Boss 战）
> **创建日期:** 2026-05-16
> **策略:** 方案一 — 稳定逐层填充，每版本独立可验证

---

## 版本路线总览

```
v0.5.0 ✅ 当前 ── 127 测试、零警告、全渲染特性（云天空盒/武器模型/弹道拖尾/动态光照/粒子/天气/水下/Y-shearing）

v0.5.1 🔜 音频 ── SFX 播放管线 + 环境音效触发 + 音量控制接口（game-audio-engineer）
v0.5.2 🔜 菜单 ── 主菜单/暂停/设置/结算 4 场景（ui-programmer）
v0.5.3 🔜 关卡 ── 2 张精心打磨的地图 + 敌人/拾取物分布（level-designer）
v0.5.4 🔜 叙事 ── 中文简报/胜利失败文本/拾取物描述（narrative-designer）
v0.5.5 🔜 打磨 ── 全项目审查 + 数值平衡 + Bug 修复（lead-programmer + qa-tester）
v0.6.0 🔜 里程碑 ── 有声有菜单有关卡有剧情的可玩 DEMO

v0.6.1 🔜 音乐 ── 自适应背景音乐 + Boss 战斗音乐（game-audio-engineer）
v0.6.2 🔜 Boss  ── 2 种 Boss 敌人 + 关卡终局战斗（gameplay-programmer）
v0.6.3 🔜 视觉 ── 区域高度变化 + 传送门/镜面效果（technical-artist）
v0.6.4 🔜 存档 ── 多槽位存档 + 设置持久化 + 新游戏/继续（gameplay-programmer）
v0.6.5 🔜 测试 ── 全流程测试 + 性能调优 + 终极打磨（qa-tester）
v0.7.0 🔜 成品 ── 发布包 + 版本标记（lead-programmer）
```

## 风险与缓解

| 风险 | 概率 | 影响 | 缓解 |
|------|------|------|------|
| SDL2_mixer 音频延迟 | 中 | 音画不同步 | buffer size 1024→512，预加载所有音效 |
| RenderSystem.cpp 超 1000 行 | 高 | 维护困难 | v0.5.5 审查时评估拆分策略 |
| Boss 战复杂度超预期 | 中 | v0.6.2 延迟 | Boss 行为模板化，Phase 转换状态机复用 EnemyAI |
| 存档兼容性问题 | 低 | 配置变更后读档失败 | JSON 版本字段 + 默认值回退 |
| 字体缺失（非中文 Windows）| 低 | 文字无法显示 | 回退链已有 4 级 Windows 系统字体 |
