## 一、背景与目标

- **现状**：map2 已有 49 栋 `cityBlocks` 装饰体块（实心、不可进入）+ 3 栋可进入平房（转运站/便利店/派出所）。
- **用户反馈**：楼宇布局已好，但大量建筑只是背景，未发挥价值；希望第二关任务能**进入其中一些建筑**（含**可进入且不止一层**的），并为**商铺/公寓/办公楼**配套**新立面贴图**。
- **目标**：把街区从"布景"升级为"可探索的关卡空间"——选定若干建筑改为**可进入多层**，每栋承载一个**室内任务**，不同建筑类型有**专属立面贴图**。

## 二、可进入多层建筑：复用既有 `layers` 系统

### 2.1 数据模型（已存在，直接复用 map0 仓库 2F/3F 的成熟方案）

| 配置段 | 字段 | 作用 |
| --- | --- | --- |
| `buildings` | `{name,x,y,w,h,symbol,door{side,pos,w}}` | 首层外墙 + 门洞（可进入） |
| `layers` | `{map,floor,baseHeight,rect,grid[],slabHoles[],pickups[]}` | 每上层独立符号网格（上层为下层子集→自然退台）+ 楼板挖洞 + 分层拾取 |
| `stairs` | `{map,x,y,w,h,dir,height,base,steps,texture}` | 层间楼梯（`base`=起始板高，如 0→2.6→5.2） |
| `partitions` | `{map,symbol,cells[]}` | 运行时室内隔墙（进 `wall_cells`，做房间/楼梯间） |

### 2.2 从"实心体块"到"可进入多层"的改造路径

选定若干 `cityBlocks`（建议 **地标塔 + 4~6 栋沿街大楼**）改为 enterable，每栋：
1. **首层**：`buildings` 式外墙 + `door`（替代原实心 footprint 登记）。
2. **上层**：每层一条 `layers` 条目（`grid` 画房间/走廊，`slabHoles` 开楼梯井）。
3. **层间**：`stairs` 连接（双跑折返，参照 map0 楼梯1/楼梯2）。
4. **室内**：`partitions` 做隔墙/房间分隔。

**必守的既有坑（来自 A 线经验）**：
- 楼梯井格**必须**进 `slabHoles`，否则楼板碰撞 run 封死楼梯 → 玩家卡死（曾发生，已修）。
- **敌人 AI 不穿墙**（现状：站桩 / 近距离 aggro，无寻路）→ 室内战斗用**固定哨戒 + 近距离触发**，不做巡逻寻路（除非本阶段专门补，见决策点5）。
- 坐标口径：`level_ext` 落位必须对照 `wall_cells` 核验（防 MAPS 首行空行偏移）。

### 2.3 三类建筑的室内形态（建议）

| 类型 | 层数 | 室内形态 | 立面特征 |
| --- | --- | --- | --- |
| **商铺** | 1~2F | 大开间货架/柜台 + 后仓 | 大面积橱窗玻璃 + 招牌带 |
| **公寓** | 3~5F | 走廊 + 多户小房间 + 楼梯间 | 规则小窗阵列 + 阳台/空调外机 |
| **办公楼** | 5~8F（地标塔 12F） | 中庭/走廊 + 办公隔间 + 电梯井(装饰) | 网格幕墙 + 层间带 |

## 三、新立面贴图素材（商铺/公寓/办公楼）

### 3.1 生成管线（已存在，直接复用）

- **路线A（程序化）**：`assets-src/<type>/gen_<type>.py`（仿 `roads/gen_roads.py`、`gate/gen_gate.py`、`stairs/gen_stairs.py`）→ 直接输出 `128×N` BMP。可控、可复现、风格统一。
- **路线B（AI 原稿）**：`<type>_*_raw_<ts>.png`（AI 生成）→ `process_<type>.sh`（ffmpeg/ImageMagick：`crop` + `scale=…:flags=neighbor` + 调色板量化）→ BMP（仿 `facade_props/process_facade_props.sh`、`walls/process_walls.sh`）。更丰富但需迭代。
- 落位 `godot/assets/images/*.bmp` + `.import`。**改贴图源后必须 `godot --import` 刷新 `.godot` 缓存**（既有坑：曾出现"改了没生效"实为缓存未刷新）。

### 3.2 贴图清单（每类 2 张：窗格带 + 墙板带；沿用现有命名口径）

- `Facade Shop Windows.bmp` / `Facade Shop Panel.bmp`（橱窗玻璃 + 招牌）
- `Facade Apartment Windows.bmp` / `Facade Apartment Panel.bmp`（小窗阵列 + 阳台）
- `Facade Office Windows.bmp` / `Facade Office Panel.bmp`（幕墙网格 + 层间带）
- （可选）室内贴图：`Interior <Type> Wall.bmp` / `Floor.bmp`（若不复用现有墙/地贴图）
- **尺度对齐**：沿用本批窗格修复口径（`CITY_WINDOW_BAND_M=7.8`，1 带 = 2 层 = 5.2m×7.8m，每窗行 ≈1.7m 近人体高）。新贴图按同宽高比设计，避免再次失衡。

### 3.3 贴图-建筑绑定（最小配置扩展）

- `cityBlocks`/`buildings` 条目新增字段 **`"facadeType": "shop"|"apartment"|"office"|"warehouse"`**（默认 `warehouse` = 现有 `Facade Windows/Panel`）。
- `_city_block_visual` / `_build_facade` 按 `facadeType` 查一个小表选 `windowTexture`/`wallTexture`。
- **向后兼容**：无 `facadeType` → 用现有贴图，已生成的 49 栋体块零变化（回归中立）。

## 四、室内任务设计（复用 `breaker`/`gate` + `area_hints`）

### 4.1 任务机制（已存在，A批6 合闸机制）

- `wallDecals` 条目带 **`"interact": "breaker"` + `radius` + `floor`** → 玩家走近（同层、半径内）触发 → 贴图切 `onTexture` + `level.breaker_activated` 信号 → `narrative.gate` 的 toast/objective 行。
- **撤离闭锁**：`has_gate()` 且 `gate_powered==false` 时触旗不判通关 → 可把"进入某建筑完成任务"设为**通关前置**。
- `area_hints`（`{map,x,y,floor,radius,text}`，楼层感知）：室内环境叙事/伏笔。

### 4.2 每栋建筑的任务（建议）

| 建筑 | 类型/层 | 任务 | 机制 | 推进/奖励 |
| --- | --- | --- | --- | --- |
| 转运站（既有） | 仓库 1F | 追查包装转运痕迹 | `area_hints` | 伏笔衔接 map1 |
| 便利店（既有） | 商铺 1~2F | 取补给 + 合闸供电 | `breaker` + `pickups` | 通电 + 物资 |
| 派出所（既有） | 办公楼 2~3F | 军械库取霰弹/弹药 | `pickups` + `breaker` | 武器/弹药 |
| **地标塔（新）** | 办公 12F | **顶层通讯中继合闸** | `breaker(floor=12)` + 多层清剿 | **通关前置**（解锁撤离） |
| **公寓 ×2（新）** | 公寓 3~5F | 清剿寄生巢 + 找钥匙卡 | `enemies`(哨戒) + 拾取 | 可选：捷径/肥 loot |

### 4.3 与第二关主线（抵达东北信标）的编织

- **主线不变**：沿主街向东 → 东北高点信标（地下设施入口）。
- **两档建筑任务**：① **主线前置**（地标塔顶层合闸 = 撤离闭锁 gate，不通电触旗无效）；② **可选支线**（公寓/商铺 = 资源/捷径/叙事，不做也能通关但更肥）。
- **节奏弧线**：街道遭遇战（紧张）→ 进建筑室内任务（探索/清剿/解谜）→ 出建筑推进（喘息→再遭遇）→ 地标塔登顶（高潮）→ 信标撤离。
